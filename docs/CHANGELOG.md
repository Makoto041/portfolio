# CHANGELOG — 初版ハンドオフ以降の変更点

このファイルは、最初に共有した README(初版ハンドオフ)から現在の `design-reference-top.html` までの **差分だけ** をまとめたものです。初版仕様で既に実装済みなら、以下の項目のみを改修してください(ゼロから作り直す必要はありません)。最新の完成形は `design-reference-top.html`(ブラウザで直接開けます。全挙動が動作)。

---

## 0. レイアウト幅【重要・新規】
- 初版: コンテンツは中央寄せの **固定幅 1180px**(デスク背景+カード影)
- 現在: **ブラウザ横幅いっぱいのフルブリード**
  - 左右ガター 48px は維持したまま、ヒーロー/バー/メイングリッド/ギャラリー/フッターを画面幅に合わせて伸縮
  - メイングリッドは `grid-template-columns: 1fr 320px`(右レール 320px 固定、左カラムが可変で広がる)
  - 中央寄せ・カード影・デスク背景は撤去。ページ背景 `#eef1f4` が全面
  - 実装の目安: ルートは `width:100%`、最小幅 1080px 程度(ナビ・バーの折り返し防止)。それ以下はレスポンシブ方針に従って調整可

## 1. ヘッダー(タイトルバー)
- 初版: 左に macOS 風ドット + `makoto@tokyo: ~/life — {時刻}`
- 中間で 2 行ロゴをヘッダーに入れたが、**撤回**して初版のターミナルパス `makoto@tokyo: ~/life — {時刻}` に戻した。名前は下記ヒーローの大型ワードマークが担う(ヘッダーにロゴは置かない)

## 2. ヒーロー(初版の大型ヒーローを復活 + タイプライター化)
- 初版: 108px の巨大タイポ `MAKOTO`(アウトライン)/ `IWABUCHI`(ベタ)+ 大カーソル、`~/life $ whoami` 行、タグライン
- 中間で一度撤去したが、**大型ヒーローを復活**。さらに:
  - **ワードマーク(`MAKOTO`→`IWABUCHI`)を初期ロードでタイプライター表示**(90ms/字、カーソルが上段→下段へ移動)。完了後に **タグラインもタイプ**(70ms/字)→ ロールをフェードイン
  - タグライン `日々の記録、ときどき写真。つぶやきくらいの気軽さで。` と `— web engineer, tokyo` は **Payload CMS から編集可能なフィールドに**すること
  - `prefers-reduced-motion` ではタイプせず全文即表示

## 3. ステータス/ライブ環境(2本 → 1本に統合、演出を刷新)
- 初版: 「ステータスストリップ」+「ライブ環境バー」の **2本**。ステータス側に **草グリッド**(contribution、30セル)
- 現在: **1本のバーに統合**、草グリッドは **撤去**。半透明白+blur+hairline 枠、padding 9px 18px。中身:
  - 左: **ブライユ・スピナー**(⠋⠙⠹…、90ms で回転)+ `NOTICE` ラベル(固定)+ **日付バッジ**(例 `12.06`、Outfit 600 10.5px、accent 色)+ **メッセージ本文**(Noto Sans JP)
    - `NOTICE` は「お知らせ」。**日付+コメントの複数件をローテーション**(メッセージのみ 75ms/字でタイプ → 約2秒ホールド → 次の件へ。日付は即時切替。末尾に点滅カーソル 6×12px)
    - 例: `12.06 アドベントカレンダー執筆中です` / `11.28 年末の振り返り記事を準備中` / `11.20 ギャラリーに写真を50枚追加しました` / `11.12 コメント欄からのお便り、読んでます`
    - 実装では Payload のお知らせコレクション(date + body)を新しい順にローテーション
  - 縦罫線で区切り
  - **`entries: 128` / `photos: 342` / `streak: 47d` を常時並列表示**(ローテーションしない・アニメなし・実データ)
- 【不採用にした中間案】カウントアップ(0→実値)、ミニプログレスバー `[████░░░░] 62%`、STATUS 本文を1回だけタイプ — **すべて破棄**。上記 NOTICE ローテーションに置き換え

## 4. 日時・天気・現在地(挙動を「ライブ」→「固定的」に)
- 初版: `$ date && weather` ラベル + 時刻 `HH:MM:SS` を **毎秒更新**(生きている感)
- 現在: バー **右寄せの固定表示**。天気 SVG アイコン(24px)+ 気温 + `くもり · 東京` + `|` + 日付 `YYYY.MM.DD DAY` + 時刻 **`HH:MM`(秒なし)**
  - 時計は内部的に 30s 間隔で分だけ追従。**秒の刻み・カウント演出はなし**
  - 天気 SVG(晴れの光線回転を含む)・現在地取得・東京フォールバックの各ロジックは **初版どおり流用**

## 5. その他
- ロゴの点滅カーソル / スピナー / NOTICE のタイプ+カーソルは `prefers-reduced-motion` で静止
- 草グリッドを廃止したため、初版で日次集計 API を組んでいた場合は不要

## 6. タイプライター描画時のレイアウトシフト防止【新規】
- 現象: ワードマークの各行(`MAKOTO`/`IWABUCHI`)はタイプ前のテキストが空だと高さ0になり、描画に伴って高さが増え → 下の要素(ステータスバー/タイムライン)が押し下げられてガタつく
- 対策: 名前2行に `min-height`(各行の line-height 相当 = `.95em` / `.98em`)、タグライン行に `min-height:20px` を付与し、テキストが空の初期状態から最終の高さを確保
- 結果: タイプ中もヒーローの総高さは一定(208px)で、下の要素は一切動かない(CLS=0)
- 実装時: フォント読込差による揺れも避けるなら、名前行はセルフホストフォント + `size-adjust` で初回描画から高さを確定させると安全(最低 `font-display:swap`)
