# デザイン仕様 — Soda Press

iwabuchi-makoto.com のデザインシステム。パステルの地 × 1本線（黒、群青のパレットでは深い群青）× 大きな丸いロゴで組む、
自分のタイムライン（日記帳）が主役のライフログ。

雑誌サイト（POPEYE）と同じに見える組み方は使わない: 写真やカードに食い込む巨大ロゴ、
写真に重ねる段々のラベル（種類 / タイトル / 補足）、[写真の列 | 表紙 | 日付のカード] の3段組。

実装は `src/app/(frontend)/soda.css`（トークン＋全スタイル）と `src/components/soda/`。

## コンセプト

- **ティッカー**: ホーム最上部（ヘッダーの上）に、最新のおしらせ3件（赤い点・リンクなし）と最新の投稿4件
  （✎・タイムラインの該当投稿へ）が右から左へ流れる。日付はどちらも「07.05」形式、速さは項目数によらずほぼ一定
- **題字**: ホーム最上部に巨大ワードマーク「MAKOTO」。下の投稿には重ねない。PC は左に寄せ、右にカバーライン
  （LIFE LOG — TOKYO・ひとこと・号数）を縦に並べる。SP はカバーラインの下に全幅で置く
- **最新の投稿**: 題字の下にいちばん新しい投稿。文章だけなら大きな文字で、写真つきなら写真を大きく見せて
  文字は写真の下の紙面に置く（見出しはタイトルか28字以内の短い本文）。下の行に種類・日時といいね。
  長い本文は数行で畳み、「続きを読む」でタイムラインの該当投稿（`/timeline#post-{id}`）へ
- **日記帳**: タイムラインは日付ごとに「曜日の丸 + M.D + 年」の見出しを立て、その日の投稿を並べる。
  1件は「時刻・種類・いいね」の1行 + 本文 + リンク/写真（種類のラベルは日記以外だけ）
- **カード**: つくったもの・イベントは、角丸の写真（4:3）の下に「種類（枠つきの小さなラベル）/ タイトル / 補足」を置く。
  文字は写真に重ねない（ホバーで写真が少し寄り、タイトルに下線）
- **今月の色**: 地色・ロゴ・差し色の3色セットを切り替えられる。文字・線・ベタ面は黒（群青のパレットでは深い群青）
- **自分の印**: 曜日の丸、赤い点（おしらせ・最新の投稿・メニューの現在地）、ドック、袋文字のフッターロゴ

## トークン

| 種別 | トークン | 値 / 用途 |
| --- | --- | --- |
| 地色パレット | `--s-bg` `--s-logo` `--s-card` | `:root[data-palette]` が持つ。いまは群青 `#e8edfa / #3354ad / #d5def5`。既定（`:root`）はクリームソーダ `#e6f1de / #74b088 / #fbf3dc` |
| 文字・線 | `--s-ink` `--s-sub` `--s-faint` | 既定は `#141414 / #42444b / #5b5e66`。パレットが `--s-pal-ink` `--s-pal-sub` `--s-pal-faint` を持てばその色（群青は `#1b2a6b / #3a4473 / #4f5884`）。どのパレットの地・カード・紙面上でも AA 以上（`src/lib/__tests__/palette.test.ts` で確認） |
| 面 | `--s-paper` | 地色を白で 60% 薄めた紙面（最新の投稿・入力欄など） |
| 赤 | `--s-hot` `--s-hot-inv` | `#d63a1e`（群青ではベタ面の上だけ明るい `#e27562`。パレットの `--s-pal-hot-inv`）。いいね済みのハート・LIVE バッジと、目印の小さな点（おしらせ・最新の投稿・メニューの現在地）だけ |
| 角丸 | `--s-r-xl` `--s-r-l` `--s-r-m` `--s-r-s` | 26 / 20 / 14 / 6px（写真・カードは大、ラベルは小） |
| 文字サイズ | `--s-fs-cap` 〜 `--s-fs-h3` | 11 / 12.5 / 14 / 16 / 17（投稿本文）/ 20px。display は各要素の clamp |
| ガター | `--s-gut` | 16px → 32px（761px〜）→ 44px（1080px〜） |

パレット（`src/lib/palette.ts`）: クリームソーダ / 群青 / ラムネ / メロン / レモン / ピーチ / ミルク。いまは群青（`SITE_PALETTE = 'gunjo'`）。
群青は深い群青を主役に、文字・線・ベタ面（塗りのボタン・選択中のタブ・ドックの現在地・フッター・メニュー）まで深い群青にし、地・紙面・カードは同じ群青の濃淡でまとめる（差し色は使わない。赤はいいね・LIVE・目印だけ）。
淡い地に黒い線を引く雑誌サイトの組み方とは分けるため、群青は文字・線まで青にする。
`SITE_PALETTE` を `'monthly'` にすると月替わり（Asia/Tokyo の月で割当）。ホーム画面に追加したときの色（`public/post.webmanifest`）も、いまのパレットの地色にそろえる（テストで確認）。

## 書体（next/font でセルフホスト）

- **Bagel Fat One**: ロゴ「MAKOTO」と各ページの英字大見出し（Timeline / Photos …）
- **DM Sans**: 欧文・数字（時刻・日付は tabular-nums）
- **Zen Kaku Gothic New**: 和文。投稿本文は 17px / 500 / 行間 1.85
- 大きな和文見出しは `<Phrase>` で語の切れ目にだけ改行させる（`keep-all` + `<wbr>`）

## レイアウト

- **ホーム**（どの幅でも最上部はティッカー。ヘッダーより上に置き、スクロールで流れ去る）
  - PC（1080px〜）: `[最新の投稿＋タイムライン | TODAY 320px（sticky）]` の2段組。写真はその下に 5列×2段（10枚）
  - タブレット（761〜1079px）: `[本文 | TODAY 280px]`、写真は下に6列
  - SP（〜760px）: ティッカー → 題字 → 最新の投稿 → TODAY（時計の段＋最新のおしらせ1件だけの細い帯）→ タイムライン → 写真（3列×2段）。
    ヘッダーの帯の高さ分だけ題字を持ち上げ、透明な帯にカバーラインを差し込む
  - 下段: ブログ（行）/ つくったもの・イベント（写真の下に文字のカード。SP は横スワイプ＋「1 / 4」）/ プロフィール帯
- **サブページ**: 英字の大見出し（ロゴ書体・地色の淡色）+ 和文 h1 + 説明 + 罫線
- **フッター**: 反転（ベタ面の地に地色の文字。いまは深い群青）。モットー「slowly, but daily.」、全ページリンク、SNS、袋文字の MAKOTO

## 動線（SP）

- 画面下のドック（ホーム / 写真 / ブログ / プロフィール / メニュー）。現在地は黒く塗る
- ヘッダー右上の封筒アイコンからお便りへ（PC は TODAY カードにも「お便り」ボタン）
- メニューは全画面（`<dialog>`）。Esc・右上の × ・画面下の「閉じる」（ドックと同じ位置）で閉じ、フォーカスは元に戻る
- タップ領域は 44px 以上（いいね・チップ・ボタン。見た目が小さいものは擬似要素で領域を広げる）

## さっと投稿（/post）

- 自分専用の投稿画面。サイトの外枠（ヘッダー・ドック・フッター）は使わず、細い帯（戻る・「投稿」・ログイン中）と
  最大 560px の1段で組む。専用のルートレイアウト（`src/app/(post)/`）で、インラインスクリプトを持たない
- 画面: ログイン（Face ID）→ 投稿（本文・写真3枚・種類のチップ・タイトルは開いたときだけ）→ 送信中 → 完了、
  帯の「ログイン中」からログイン状態（この端末・ほかの端末・パスキー・ログアウト）。新しい端末は「この端末を登録」
- 投稿ボタンは画面の下に貼りつける。下書き（本文・タイトル・種類）は端末にだけ自動保存
- エラーは赤を使わず反転（ベタ面の地に地色の文字）で出す
- ログインした端末にだけ「投稿」ボタンを出す（目印 Cookie を見るだけ）。PC はヘッダーの「お便り」の左にピル、
  SP は親指で届く画面右下（ドックの上）に丸いボタン（地色の縁取りで本文と切り離す）

## ふるまい

- ヘッダー: ホーム最上部では透明で小ロゴを隠し、題字がヘッダーの下に潜ったら帯に切り替える
- 題字は読み込み時に1文字ずつ弾む（transform のみ・CLS なし）
- ティッカー: 文字の上へのホバー・フォーカスと、右端のボタンで一時停止（WCAG 2.2.2）。ループ用の2セット目は読み上げ・フォーカスの対象外
- 写真ビューア: 前後ボタン・←→キー・左右スワイプで移動、余白（上下の帯を含む）のクリック/Esc で閉じる。
  スワイプ直後のクリックや、写真の上で押して余白で離したドラッグでは閉じない
- TODAY: 連続投稿が途切れているときは「連続 0日」ではなく最終更新日を出す。/timeline の TODAY は PC だけ表示し、
  隠れている間（SP）は時計・天気を動かさない
- `prefers-reduced-motion`: ティッカーは流さず1セットだけを横スクロールで読ませる（一時停止ボタンは出さず、横スクロールの枠はキーボードで送れる）。題字の弾み・天気の回転・シマーを止める
