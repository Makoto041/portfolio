# デザイン仕様 — Soda Press

iwabuchi-makoto.com のデザインシステム。POPEYE（popeyemagazine.jp）と同じ遺伝子
——パステルの地 × 黒い1本線 × 大きな丸いロゴ × 写真に重なる罫線タブ——を受け継ぎつつ、
中身は自分のタイムライン（日記帳）が主役のライフログ。

実装は `src/app/(frontend)/soda.css`（トークン＋全スタイル）と `src/components/soda/`。

## コンセプト

- **表紙**: ホーム最上部に巨大ワードマーク「MAKOTO」。その下 26% にいちばん新しい投稿（カバーストーリー）が潜り込む。
  写真つきなら写真いっぱい（PC 4:3 / SP 5:4）に罫線タブを重ねる。タブの見出しはタイトル（40字まで）か28字以内の短い本文で、
  それより長い本文はタブに押し込まず写真の下の紙面に全文を置く（タブは種類・日時だけ）。文章だけなら大きな文字で見せる。
  長い本文は数行で畳み、「続きを読む」でタイムラインの該当投稿（`/timeline#post-{id}`）へ
- **日記帳**: タイムラインは日付ごとに「曜日の丸 + M.D + 年」の見出しを立て、その日の投稿を並べる。
  1件は「時刻・種類・いいね」の1行 + 本文 + リンク/写真（種類のラベルは日記以外だけ）
- **罫線タブ**: カードの見出しは「ラベル / タイトル / 補足」の3段タブを写真に重ねる（ホバーで反転）
- **今月の色**: 地色・ロゴの淡色・差し色の3色セットを切り替えられる。黒は線と文字だけ
- **自分の印**: 曜日の丸、赤い点（ティッカーのおしらせ・メニューの現在地）、ドック、袋文字のフッターロゴ。
  ☞ は TODAY のおしらせだけに使う（POPEYE の意匠をそのまま重ねすぎない）

## トークン

| 種別 | トークン | 値 / 用途 |
| --- | --- | --- |
| 地色パレット | `--s-bg` `--s-logo` `--s-card` | `:root[data-palette]` が持つ。既定は群青ソーダ `#e3e8f8 / #95a1da / #f0e6c0`（クリーム） |
| 文字・線 | `--s-ink` `--s-sub` `--s-faint` | `#141414 / #42444b / #5b5e66`。どのパレットの地・カード・紙面上でも AA 以上 |
| 面 | `--s-paper` | 地色を白で 60% 薄めた紙面（カバーストーリー・入力欄など） |
| 赤 | `--s-hot` | `#d63a1e`。いいね済みのハートと LIVE バッジのみ |
| 角丸 | `--s-r-xl` `--s-r-l` `--s-r-m` `--s-r-s` | 26 / 20 / 14 / 6px（写真・カードは大、タブは小） |
| 文字サイズ | `--s-fs-cap` 〜 `--s-fs-h3` | 11 / 12.5 / 14 / 16 / 17（投稿本文）/ 20px。display は各要素の clamp |
| ガター | `--s-gut` | 16px → 32px（761px〜）→ 44px（1080px〜） |

パレット（`src/lib/palette.ts`）: 群青ソーダ / ラムネ / メロン / レモン / ピーチ / ミルク。
`SITE_PALETTE` を `'monthly'` にすると月替わり（Asia/Tokyo の月で割当）。

## 書体（next/font でセルフホスト）

- **Bagel Fat One**: ロゴ「MAKOTO」と各ページの英字大見出し（Timeline / Photos …）
- **DM Sans**: 欧文・数字（時刻・日付は tabular-nums）
- **Zen Kaku Gothic New**: 和文。投稿本文は 17px / 500 / 行間 1.85
- 大きな和文見出しは `<Phrase>` で語の切れ目にだけ改行させる（`keep-all` + `<wbr>`）

## レイアウト

- **ホーム**
  - PC（1080px〜）: `[写真の柱 172px | カバーストーリー＋タイムライン | TODAY 300px（sticky）]`
  - タブレット（761〜1079px）: `[本文 | TODAY 280px]`、写真は下に6列
  - PC の写真の柱は最大10枚。タイムラインの行の高さまで伸ばして写真を等間隔に散らし、「写真をもっと見る」を下端にそろえる
    （柱の長さの差はタイムラインの行が引き受け、表紙の行は中身の高さのまま）
  - SP（〜760px）: カバーストーリー → TODAY（時計の段＋最新のおしらせ1件だけの細い帯）→ タイムライン → 写真（3列×2段）。
    ヘッダーの帯の高さ分だけ表紙を持ち上げ、透明な帯にカバーラインを差し込む。文章だけの表紙や、写真だけ・短い見出しの
    写真の表紙なら、最初の画面（390×844）にタイムラインの1件目まで入る（写真の下に本文が続くときは、表紙の投稿そのものが
    最初の画面を占める）
  - 下段: ブログ（行）/ つくったもの・イベント（タブカード。SP は横スワイプ＋「1 / 4」）/ プロフィール帯
- **サブページ**: 英字の大見出し（ロゴ書体・地色の淡色）+ 和文 h1 + 説明 + 罫線
- **フッター**: 反転（黒地に地色の文字）。モットー「slowly, but daily.」、全ページリンク、SNS、袋文字の MAKOTO

## 動線（SP）

- 画面下のドック（ホーム / 写真 / ブログ / プロフィール / メニュー）。現在地は黒く塗る
- ヘッダー右上の封筒アイコンからお便りへ（PC は TODAY カードにも「お便り」ボタン）
- メニューは全画面（`<dialog>`）。Esc・右上の × ・画面下の「閉じる」（ドックと同じ位置）で閉じ、フォーカスは元に戻る
- タップ領域は 44px 以上（いいね・チップ・ボタン。見た目が小さいものは擬似要素で領域を広げる）

## ふるまい

- ティッカー: おしらせ（赤い点・リンクなし）＋最新の投稿（✎・タイムラインの該当箇所へ）が流れる。
  ホバー/フォーカス/右端ボタンで停止。右端は一時停止ボタンの手前でフェード
- ヘッダー: ホーム最上部では透明で小ロゴを隠し、表紙ロゴがヘッダーの下に潜ったら帯に切り替える
- 表紙ロゴは読み込み時に1文字ずつ弾む（transform のみ・CLS なし）
- 写真ビューア: 前後ボタン・←→キー・左右スワイプで移動、余白（上下の帯を含む）のクリック/Esc で閉じる。
  スワイプ直後のクリックや、写真の上で押して余白で離したドラッグでは閉じない
- TODAY: 連続投稿が途切れているときは「連続 0日」ではなく最終更新日を出す。/timeline の TODAY は PC だけ表示し、
  隠れている間（SP）は時計・天気を動かさない
- `prefers-reduced-motion`: ティッカーは流さず1セットだけを横スクロール、弾み・回転・シマーは止める
