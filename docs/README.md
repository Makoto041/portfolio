# デザイン仕様 — Soda Press（日記帳 × フィルムカメラ）

iwabuchi-makoto.com のデザインシステム。パステルの地 × 黒い1本線 × 丸いロゴを土台に、
**紙の日記帳とフィルムカメラ**の手ざわりで組む。雑誌の表紙の文法（写真に重ねる巨大ロゴ・罫線タブ・
流れるティッカー）は使わず、タイムライン（日記帳）が主役のライフログにする。

実装は `src/app/(frontend)/soda.css`（トークン＋全スタイル）と `src/components/soda/`。

## コンセプト

- **きょうのページ**: ホーム最上部は左寄せの題字「MAKOTO」と、朱のインクで押した**日付印**（TODAY / YYYY.MM.DD /
  曜日 · TOKYO）。時刻と東京の天気は日付印に添える1行。表紙の写真にロゴを重ねることはしない
- **最新の投稿**: 文章だけなら**罫線のノートの1ページ**（文字の行に横罫をそろえ、上辺をマスキングテープで留める）、
  写真つきなら**プリント**（白いフチ・右下に**フィルムの日付写し込み** `'25 10 12`・下の余白に手書きの添え書き）。
  長い本文は数行で畳み、「続きを読む」でタイムラインの該当投稿（`/timeline#post-{id}`）へ
- **日記帳**: タイムラインは日付ごとに「曜日の丸（日曜は朱）+ M.D + 年 + きょう/きのう/○日前」の見出しを立て、
  その日の投稿を並べる。写真はプリントで並べ、1枚目に日付を写し込む
- **紙もの**: おしらせは上がミシン目の**メモ帳**（SP はホームに1行の**ピン留め**）、最近の写真は黒い台紙の**ベタ焼き**
  （コマ番号つき）、見出しはノートの**インデックスタブ**（件数のバッジ）、つくったものは少し傾けて貼った**ステッカー**、
  イベントは日付の半券がついた**チケット**
- **今月の色**: 地色・ロゴ・差し色の3色セットを切り替えられる。黒は線と文字だけ。既定はクリームソーダ

## 書体（next/font でセルフホスト）

- **Bagel Fat One**: ロゴ「MAKOTO」、サブページ見出しに添える英字、フッターの袋文字
- **DM Sans**: 欧文・数字（時刻・日付は tabular-nums）
- **Zen Kaku Gothic New**: 和文。投稿本文は 17px / 500 / 行間 1.85
- **Klee One**: 手書きの添え書き（プリントのキャプション・メモ帳）
- **Doto**: フィルムの日付写し込み・ベタ焼きのコマ番号
- 大きな和文見出しは `<Phrase>` で語の切れ目にだけ改行させる（`keep-all` + `<wbr>`）

## レイアウト

- **ホーム**
  - PC（1080px〜）: `[日記（最新の投稿＋タイムライン）| 脇 320px（メモ帳・ベタ焼き）]`。脇は画面に収まる高さ（860px〜）のときだけ追従
  - タブレット・SP: 1段。最新の投稿 → おしらせのピン留め → タイムライン → ベタ焼き（タブレットは6コマ）→ メモ帳
  - 下段: ブログ（行）/ つくったもの（ステッカー。SP は横スワイプ）/ イベント（チケット）/ プロフィール帯
- **タイムライン**: 月の目次（その月だけを表示。もう一度押すと解除）と種類のチップ。PC は脇にメモ帳とベタ焼き
- **サブページ**: 1行の見出し（和文 h1 + 丸い書体の英字）+ 説明 + 罫線。大見出しで画面を使わず、すぐ一覧に入る
- **フッター**: 反転（黒地に地色の文字）。モットー「slowly, but daily.」、全ページリンク、SNS、袋文字の MAKOTO

## 動線（SP）

- 画面下のドック（ホーム / 写真 / ブログ / プロフィール / メニュー）。現在地は黒く塗る
- ヘッダー右上の封筒アイコンからお便りへ（メモ帳にも「お便りを送る」）
- おしらせのピン留めをタップすると下のメモ帳（全件）へ
- メニューは全画面（`<dialog>`）。Esc・右上の × ・画面下の「閉じる」（ドックと同じ位置）で閉じ、フォーカスは元に戻る
- タップ領域は 44px 以上（いいね・チップ・ボタン。見た目が小さいものは擬似要素で領域を広げる）

## ふるまい

- 日付印・時刻: 静的生成された HTML は生成時刻で描き、表示後にいまの日付・時刻へ追従する（30秒ごと）。
  日付印は読み込み時に一度だけ「押す」動き（transform のみ）
- きょう/きのう/○日前: 見る時刻で変わるため HTML には出さず、表示後にクライアントで計算する（暦の日・月で数える）
- ヘッダー: ホームで題字が見えている間は小ロゴを隠し、題字がヘッダーの下に隠れたら出す。PC ナビの現在地は下線
- 題字は読み込み時に1文字ずつ弾む（transform のみ・CLS なし）
- 写真ビューア: 前後ボタン・←→キー・左右スワイプで移動、余白（上下の帯を含む）のクリック/Esc で閉じる。
  スワイプ直後のクリックや、写真の上で押して余白で離したドラッグでは閉じない
- `prefers-reduced-motion`: 題字の弾み・日付印・天気の回転・シマーを止める
